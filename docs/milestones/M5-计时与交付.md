6. 端口必须随机探测，**不许硬编码**
7. 打包用 `--onedir`，不用 `--onefile`

## 6. 本里程碑技术细节

### 6.1 计时：只用时间戳

```js
// 状态只存三个时间点，不存"还剩多少秒"
state = { startTime, pausedAccum, pausedAt, planned }

get elapsed() {
  const now = state.pausedAt ?? Date.now();
  return (now - state.startTime) / 1000 + state.pausedAccum;
}
remaining = planned - elapsed
```

- `setInterval` **只负责触发重算与渲染**（1s），不负责累加
- 暂停：`pausedAccum += (now - startTime)/1000`；恢复：`startTime = now; pausedAt = null`
- 后端 `study_session.duration_seconds` 用同样的口径在结束时一次性算好

### 6.2 刷新与重启恢复

- 前端挂载时 `GET /api/session/current`，有 running（或 paused）就续上
- 每 15 秒 `POST /api/session/{id}/heartbeat` 卷一次账（防止强杀进程丢时长）。
  **用 POST 不用 PATCH**：闭窗兜底要走 `navigator.sendBeacon`，它只能发 POST（2026-11-08 实测后定）
- `beforeunload` 里同步发一次 `navigator.sendBeacon`（异步 fetch 会被中断）
- 后端启动时把**会话开始**超过 4 小时仍 `running`/`paused` 的 session 标为 `abandoned`，
  时长按 `planned_seconds` 封顶（判据用 `created_at` 不用 `start_time`：心跳会把锚点一直往前挪）

### 6.3 Electron 主进程关键代码

```js
const net = require('net')
const { spawn } = require('child_process')

function freePort() {
  return new Promise(resolve => {
    const srv = net.createServer()
    srv.listen(0, '127.0.0.1', () => {
      const p = srv.address().port
      srv.close(() => resolve(p))
    })
  })
}

async function waitHealthy(port, timeoutMs = 30000) {
  const t0 = Date.now()
  while (Date.now() - t0 < timeoutMs) {
    try {
      const r = await fetch(`http://127.0.0.1:${port}/api/health`)
      if (r.ok) return true
    } catch {}
    await new Promise(r => setTimeout(r, 300))
  }
  return false
}
```

**握手用 HTTP 轮询，不用 stdout 读 `READY`。** 原因：打包成 windowed exe 后 `sys.stdout` 是 `None`，读不到输出（ADR-016）。

```js
const port = await freePort()
const dataDir = app.getPath('userData')       // %APPDATA%/Cairn
const child = isDev
  ? spawn('uv', ['run','uvicorn','app.main:app','--port',String(port),'--data-dir',dataDir],
          { cwd: backendDir, shell: true })
  : spawn(path.join(process.resourcesPath,'backend','cairn-backend.exe'),
          ['--port',String(port),'--data-dir',dataDir], { windowsHide: true })

if (!await waitHealthy(port)) { dialog.showErrorBox('启动失败','后端未能在 30 秒内就绪'); app.quit() }

win = new BrowserWindow({ webPreferences: { preload, contextIsolation: true, nodeIntegration: false } })
```

`preload.js`：

```js
contextBridge.exposeInMainWorld('api', { baseUrl: `http://127.0.0.1:${port}` })
```

退出清理：

```js
app.on('before-quit', () => { try { child.kill() } catch {} })
process.on('exit', () => { try { child.kill() } catch {} })
```

### 6.4 为什么"先打空壳包"必须提前

打包失败**几乎从不是代码问题**，而是：

- PyInstaller 没带上 `templates/` `prompts/` → 运行时 `FileNotFoundError`
- `sys._MEIPASS` 路径没兼容 → 同上
- windowed 模式 `stdout=None` → 打印就崩
- 数据库路径写到了 `C:\Program Files\...`（无写权限）→ 启动即 500
- Defender 拦截未签名 exe
- 端口冲突、子进程残留

这些在 M1 就能用一个"只有 `/api/health` 的空壳"提前暴露。**成本 2 小时，省下的是一整天的排查。**

```python
def resource_path(rel: str) -> Path:
    base = Path(getattr(sys, "_MEIPASS", Path(__file__).parent))
    return base / rel

DATA_DIR = Path(args.data_dir or os.getenv("DATA_DIR", "./data"))
# 所有可写的东西（data.db / models / logs / tmp）一律在 DATA_DIR 下
# 所有只读的东西（templates / prompts）走 resource_path()
```

### 6.5 打包命令

```bash
# 后端
pyinstaller --noconfirm --onedir --name cairn-backend \
  --add-data "app/templates;app/templates" \
  --add-data "app/prompts;app/prompts" \
  run.py
# 注意 --windowed 与 --console 的选择：
#   带控制台 → 用户会看到黑框（体验差）
#   不带控制台 → 出错时看不到日志，必须写文件日志
# 结论：用 windowed，日志强制写 data/logs/app.log，并在设置页提供"打开日志目录"按钮
```

electron-builder 配置里 `extraResources` 把 `dist/cairn-backend/` 整体塞进 `resources/backend/`，`asar: true`，`appId: "com.cairn.app"`，`productName: "Cairn"`，`nsis: { oneClick: false, allowToChangeInstallationDirectory: true }`。

### 6.6 统计口径（必须写死在文档里，否则每次算得不一样）

| 指标 | 口径 |
|---|---|
| 今日待整理 | `knowledge_item WHERE status='pending' AND date(created_at, 'localtime') = date('now','localtime')`（另给 `pending_total` = 全库待整理，因为昨天的没整理完不算今日新增） |
| 今日待复习 | `review_item WHERE due_at <= now` 总条数（不限今日新增） |
| 本周专注时长 | 本周一 00:00 起，`status='done'` 的 `duration_seconds` 之和（`abandoned` 不计） |
| 连续学习天数 | 从今天往前推，每天至少有一条 `done` session 的连续天数。**今天还没学不算断**，从昨天起算（否则每天零点一过就归零，2026-11-08 补的澄清） |
| 正确率 | `is_correct=1` 的数量 / `is_correct IS NOT NULL` 的数量（**NULL 不计入分母**） |
| 分类分布 | `GROUP BY category` 取前 8 |

`verify_m5.py` 要用同一套口径算一遍，和接口返回值比对。

## 7. 排障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 打包后白屏 | 后端没起来就建窗口 / `baseUrl` 是 undefined | 检查 `waitHealthy` 是否真的 await；preload 是否被 `contextIsolation` 挡住 |
| 打包后 `FileNotFoundError: templates/` | `--add-data` 漏了或路径分隔符写成 `/` | Windows 用 `;` 分隔；用 `resource_path()` 读 |
| 打包后启动即 500，日志 `unable to open database file` | 数据目录不可写 | 确认 `--data-dir` 指向 `%APPDATA%`；不要用 `Path.cwd()` |
| 双击没反应 | windowed 模式下异常被吞 | 写文件日志；临时换成 console 模式复现一次 |
| Defender 报毒 | 未签名 + 单文件自解压 | 用 onedir；README 说明；必要时加排除项 |
| 关窗口后进程还在 | 没 kill 子进程 | `before-quit` + `exit` 双保险；任务管理器验证 |
| 系统时间改回后待复习消失 | due 用本地时间算 | 统一 UTC，Python 侧比较 |
| 计时器跳秒/漂移 | 用计数器累加 | 改时间戳推算 |
| 换机器后模型重新下载 | 模型在安装目录 | 移到 `%APPDATA%/Cairn/models/` |
