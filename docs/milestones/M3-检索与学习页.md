## 1. 本里程碑不可让步的约束

1. FTS5 **已经**是 `trigram`；若发现不是，停下来重灌，不要将就
2. 查询词 <3 字符时**必须**走 `LIKE` 兜底，否则两字词全查不到
3. bge 模型：**文档向量不加前缀，查询向量加** `为这个句子生成表示以用于检索相关文章：`
4. 检索为空时**不许调用 LLM**，直接返回固定话术（防编造）
5. 生成的 HTML **必须自包含**（样式内联、无外链 CDN），断网可开
6. 生成的 HTML **必须做 HTML 净化**，不许直接拼 LLM 输出；净化白名单**必须放行 SVG 标签**，否则导图会被吃掉
7. 不引独立向量库；向量表与业务表在同一个 `data.db`
8. 思维导图**由后端生成 SVG**，不引 markmap / mermaid / d3（ADR-017）
9. 导图**不落库**，每次现场从 `structured_note` 生成（ADR-019）
10. SVG 里的文字必须 XML 转义，输出不许含 `<script>` 与外链

## 6. 本里程碑技术细节

### 6.1 全文检索（两段式）

```python
def search_fts(q, limit=20):
    if len(q.strip()) < 3:
        # trigram 对 <3 字符无效，走 LIKE
        rows = conn.execute(
            "SELECT c.id, c.item_id, c.content FROM chunk c "
            "WHERE c.content LIKE ? LIMIT ?", (f"%{q}%", limit)).fetchall()
        return [(r, "like") for r in rows]
    rows = conn.execute(
        "SELECT c.id, c.item_id, c.content, bm25(chunk_fts) AS score "
        "FROM chunk_fts JOIN chunk c ON c.id = chunk_fts.rowid "
        "WHERE chunk_fts MATCH ? ORDER BY score LIMIT ?", (q, limit)).fetchall()
    return [(r, "fts") for r in rows]
```

- `bm25()` 越小越相关，`ORDER BY score` 是升序
- 用户输入里若有 `"` `*` `:` 等 FTS 语法字符，先做**参数化清洗**（包成 `"..."` 短语或剔除），否则会抛 `fts5: syntax error`
- snippet 自己在 Python 里截：命中位置前后各 60 字

### 6.2 Embedding

```python
from sentence_transformers import SentenceTransformer
_model = None

def get_model():
    global _model
    if _model is None:
        _model = SentenceTransformer("BAAI/bge-small-zh-v1.5",
                                     cache_folder=str(DATA_DIR / "models" / "embedding"))
    return _model

QUERY_PREFIX = "为这个句子生成表示以用于检索相关文章："

def encode_docs(texts):   return get_model().encode(texts, batch_size=32,
                            normalize_embeddings=True)
def encode_query(q):      return encode_docs([QUERY_PREFIX + q])[0]
```

- `normalize_embeddings=True` 后，余弦相似度退化为点积，numpy 降级时直接 `mat @ q`
- 首次加载约 3 秒，务必**懒加载并常驻**，不要每次请求重建
- 入库时异步补向量（`agent_task` type=`index_embed`），不要卡在采集流程里
- 缓存目录必须是 `data/models/embedding`（`env_probe.check_embedding()` 探的就是这个路径，
  换地方会让设置页永远显示"未下载"）。请求路径**不许触发下载**，只有 `index_embed`
  任务与 `scripts/backfill_embed.py` 会真的拉模型

### 6.4 RRF 融合

```python
def rrf(*ranked_lists, k=60, top=8):
    score = {}
    for lst in ranked_lists:
        for rank, cid in enumerate(lst, start=1):
            score[cid] = score.get(cid, 0) + 1.0 / (k + rank)
    return sorted(score, key=score.get, reverse=True)[:top]
```

两路各取 top-20，融合后取 8。**不要**把 bm25 分数和余弦相似度直接相加。

### 6.5 SSE 的三个坑

1. **必须** `async def` 生成器 + `StreamingResponse(gen(), media_type="text/event-stream")`
2. **必须**加响应头 `{"Cache-Control": "no-cache", "X-Accel-Buffering": "no"}`
3. 若全局挂了 `GZipMiddleware`，SSE 会被缓冲成一次性返回——**对 `/api/ask` 与 `/api/quiz/generate` 排除 gzip**
4. 阻塞的检索与 LLM 调用用 `await run_in_threadpool(...)` 包住，否则卡住事件循环

### 6.6 思维导图生成（纯 Python 出 SVG，零依赖）

**为什么要自己写**：见 ADR-017。一句话——导出 HTML 必须单文件离线，前端 JS 库内联不进去。

**解析**

```python
def parse_tree(md, fallback_title, fallback_points):
    root = Node(fallback_title)
    stack = [(0, root)]
    for line in md.splitlines():
        m = re.match(r"^(#{1,6})\s+(.+)", line)
        if m:
            level, text = len(m.group(1)), m.group(2).strip()
            node = Node(text)
            while stack and stack[-1][0] >= level:
                stack.pop()
            stack[-1][1].children.append(node)
            stack.append((level, node))
    if not root.children:                      # 无标题时退化
        root.children = [Node(p) for p in fallback_points[:8]]
    return root
```

**注意**：第一个 `#` 要挂到根**下面**，不能取代根，否则条目标题就丢了。

**布局（横向树，四步）**

```
1. 后序：叶子占 28 + 8 的纵向槽；非叶子 y = 首子 y 与末子 y 的中点
2. 每一层的 x = 前面所有层「最宽节点 + 64」的累加
3. 全部算完再定 viewBox = (最右 + 32, 最下 + 32)
```

> **实施偏差（2026-11-07）**：原方案写 `x = 层级 × 200`，实做时发现 22 字标题宽约 310px，
> 会压到下一层的框上。改成「按层累加最宽节点」后，窄笔记的间距与固定 200 接近，
> 宽笔记自动拉开。宽度估算也按字符类型分开：全角 13px、其余 7.2px。

**绘制**

```
节点   <rect rx="8" fill="#E1F5EE" stroke="#1D9E75" stroke-width="0.5"/>
       <text dominant-baseline="central" font-size="13">…</text>
连线   M x1 y1 C x1+60 y1, x2-60 y2, x2 y2   fill="none" stroke-width="1.2"
配色   根 / L2 / L3 / L4 四档写死 hex（导出 HTML 要自带颜色）
```

**必须做的四件事**

1. `html.escape(text)` 之后才放进 `<text>`，否则笔记里的 `<` 直接把 SVG 搞坏
2. 节点文字 >24 字符截为 22 字 + `…`
3. 深度超过 4 级折叠进第 4 级（导图是概览，不是全文）
4. 输出里不许出现 `<script>`、`<style>` 外链、`<image xlink:href>`

**中文宽度估算**：`len(text) * 13 + 24`。中英混排必然有偏差，宁可算宽一点——留白不影响观感，重叠才是灾难。

**不缓存**（ADR-019）。笔记一改导图必须立刻变，缓存收益 2ms 不值得换一次不一致。

### 6.7 HTML 生成（关键：内联一切）

```python
md = markdown.Markdown(extensions=[
    "fenced_code", "tables", "toc", "sane_lists",
    "codehilite",          # 配合 Pygments
], extension_configs={
    "codehilite": {"noclasses": True, "pygments_style": "friendly"},
    #                               ↑ 关键：生成行内 style，不要 class
    "toc": {"permalink": False},
})
```

- `noclasses=True` 是"单文件离线可开"的**唯一**做法。用 class 就必须外链 CSS，断网就废
- 模板里把 base CSS 直接写进 `<style>`，不要引任何 CDN
- 结构：`<h1>标题</h1>` → 元信息（来源/生成时间/条目数）→ `[TOC]` → 每条目一节（**思维导图 SVG** / 摘要 / 关键点 / 结构化笔记）→ 页脚
- 导图直接内联在条目小节开头，**不要用 `<img src="data:...">`**，直接放 `<svg>` 最省事也最稳
- **净化**：`bleach.clean(html, tags=[...白名单...], attributes={"a": ["href"], "*": ["class","style"]}, strip=True)`。`style` 要放行（Pygments 用），但 `script/iframe/on*` 一律清除。**`svg` 相关标签必须放行**（否则导图会被 bleach 吃掉），但只放行 `svg path rect text g circle line`，`script foreignObject` 必须禁
- 条目原文里的 `<` `>` 在转 Markdown 前先 `html.escape`，避免被当成标签

### 6.8 下载

`FileResponse` 或手动构造 `Response(content=html, media_type="text/html", headers={"Content-Disposition": 'attachment; filename="xxx.html"'})`。**文件名必须 URL 编码**（`urllib.parse.quote`），否则中文文件名在部分浏览器会乱码。

## 7. 排障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 搜两字词零结果 | trigram 对 <3 字符无效 | 确认走了 LIKE 分支；`len(q) < 3` 判断别写成 `<= 3` |
| `fts5: syntax error near "*"` | 用户输入含 FTS 语法字符 | 输入清洗：把 `"` 换成空格，整体包成短语查询 |
| 搜什么都搜不到，但库里有数据 | 触发器没建 / 建表时 tokenizer 写错 | `SELECT count(*) FROM chunk_fts` 应为非 0；验 `sqlite_master.sql` 是否含 `trigram` |
| 向量查询报 `no such module: vec0` | 扩展未加载 | 检查 `enable_load_extension` 与 `sqlite_vec.load`；失败即降级，不要重试 |
| SSE 一次性吐出全部内容 | gzip 缓冲 / 中间层缓冲 | 排除 gzip + 加 `X-Accel-Buffering: no` |
| 模型下载卡住 | 国内访问 HF 慢 | 设 `HF_ENDPOINT=https://hf-mirror.com`，写进 `.env.example` |
| 生成的 HTML 断网没样式 | 用了 `noclasses=False` 或引了 CDN | 改 `noclasses=True`；搜一遍输出里有没有 `http` |
| 预览 iframe 白屏 | sandbox 太严 | 用 `sandbox="allow-same-origin"`；不要加 `allow-scripts` |
| 问答开始编造 | 检索为空仍调了模型 | 加硬短路：`if not chunks: return no_result` |
| 导图是一张白图 | viewBox 算成 0 / 根节点没子节点 | 打印 maxX、maxY；无标题时走 key_points 退化分支 |
| 导图节点文字消失 | 没做 `html.escape`，笔记里的 `<` 把标签截断了 | 转义后再进 `<text>`；用 XML 解析器验一遍输出 |
| 导出 HTML 里导图不见了 | bleach 白名单没放行 `svg/rect/text/path` | 白名单加上（但不许放 `script`、`foreignObject`） |
| 改完笔记导图没变 | 加了缓存没失效 | 去掉缓存（ADR-019），或按 `sha256(structured_note)` 做 key |
| 导图节点重叠 | 中文宽度估算偏小 | 系数从 13 调到 15，或按字符类型分别计算（中文 14px / 英文 7px） |
| 导图节点过多挤成一坨 | 笔记里标题太多 | 深度截到 4 级、列表项最多 8 个；这属于笔记结构问题，不是渲染问题 |
