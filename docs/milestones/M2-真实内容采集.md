## 1. 本里程碑不可让步的约束

1. 网页与视频**都必须走 adapter 接口**（`BaseFetcher` / `BaseTranscriber`），不许把 trafilatura / yt-dlp 直接写进路由
2. 所有采集都是**异步任务**，路由不许在请求线程里下载或转录
3. 失败必须分类到具体错误码，前端要显示**人话**，不是堆栈
4. 同一 URL 不许重复入库；同内容不同 URL 要提示而非静默新建
5. 转录默认 `small` 模型，**不默认 large**（6GB 显存扛不住且慢）
6. 不做反爬绕过、不处理登录态；抓不到就明确告诉用户"改用粘贴文本"

## 3. 目标与验收场景

**一句话**：把网页链接和视频链接丢进去，它自己去抓、去转录，进度看得见、失败读得懂。

**验收场景 A（网页）**：粘一个技术博客 URL → 任务从 queued→running→done，约 5 秒 → 知识库出现条目，正文干净无导航栏 → 点整理能正常跑通。

**验收场景 B（视频）**：粘一个 5 分钟 B 站视频 → 进度条走 downloading(0–30%) → transcribing(30–95%) → saving → 完成 → 打开条目看到带时间戳的转录文本。

**验收场景 C（失败）**：粘 `https://example.com/not-exist-xxx` → 任务 failed，页面显示"目标页面不存在或已删除"，不产生脏数据。

## 6. 本里程碑技术细节

### 6.1 网页抓取实现

```python
UA = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 ... Chrome/120 Safari/537.36"

resp = httpx.get(url, follow_redirects=True, timeout=30, headers={"User-Agent": UA})
resp.raise_for_status()
if "html" not in resp.headers.get("content-type", ""):
    raise FetchError("FETCH_INVALID", "该链接不是网页（可能是文件或图片）")
text = trafilatura.extract(
    resp.text,
    include_comments=False, include_tables=True,
    favor_recall=True, output_format="txt",
)
meta = trafilatura.extract_metadata(resp.text)
```

- `favor_recall=True`：宁可多留一点，也别把正文裁掉。中文长文用这个更稳
- `trafilatura` 自己会做正文密度打分，不需要再写规则
- **不要**用 `trafilatura.fetch_url`（它内部的 urllib 不好控制超时与 UA）

### 6.2 错误码映射（照抄）

| 触发条件 | 错误码 | 中文文案 |
|---|---|---|
| `httpx.TimeoutException` | `FETCH_TIMEOUT` | 目标站点响应超时，请稍后重试 |
| `ConnectError` / DNS 失败 | `FETCH_DNS` | 无法连接到该站点，请检查链接或网络 |
| 403 / 429 | `FETCH_BLOCKED` | 目标站点拒绝访问（可能需要登录或限制抓取） |
| 404 / 410 | `FETCH_NOT_FOUND` | 目标页面不存在或已删除 |
| content-type 非 html | `FETCH_INVALID` | 该链接不是网页 |
| 正文 < 200 字 | `FETCH_EMPTY` | 未能提取到正文（可能是动态渲染页面），建议改用粘贴文本 |

### 6.3 视频流水线

**阶段一 · 元数据**（`stage="metadata"`，progress 0–5）

```python
with yt_dlp.YoutubeDL({"quiet": True, "no_warnings": True, "noplaylist": True}) as ydl:
    info = ydl.extract_info(url, download=False)
title, duration = info["title"], info.get("duration", 0)
```

**阶段二 · 下载音频**（`stage="downloading"`，5–30）

```python
opts = {
    "format": "bestaudio/best",
    "outtmpl": str(tmp / "%(id)s.%(ext)s"),
    "quiet": True, "no_warnings": True, "noplaylist": True,
    "postprocessors": [{"key": "FFmpegExtractAudio",
                        "preferredcodec": "wav", "preferredquality": "16"}],
}
```

**阶段三 · 转录**（`stage="transcribing"`，30–95）

```python
device = "cuda" if _cuda_ok() else "cpu"
compute = "float16" if device == "cuda" else "int8"
model = WhisperModel(size, device=device, compute_type=compute,
                     download_root=str(MODELS_DIR / "whisper"))
segments, info = model.transcribe(str(wav), language="zh", vad_filter=True, beam_size=5)
for seg in segments:                       # 生成器，边转边回报
    on_progress(int(seg.end / info.duration * 65) + 30)
    lines.append(f"[{_ts(seg.start)}] {seg.text.strip()}")
```

- `_cuda_ok()`：try 建一个 float16 模型，失败返回 False。**不要**只判断 `torch.cuda.is_available()`，cuDNN 版本不匹配时照样失败
- 模型放 `data/models/whisper/`，不要放用户缓存目录（卸载重装会丢）
- 首次使用会下载模型，进度条要显示"正在下载模型（约 500MB）"

**阶段四 · 落库**（`stage="saving"`，95–100）
写入 `knowledge_item`，`raw_content` 为 `\n`.join(lines)，标题用视频标题。

### 6.4 进度回报的落地方式

`on_progress` 不要每次 segment 都写库（几百次写库会锁表）。做法：

```python
_last = [0]
def on_progress(p):
    if p - _last[0] >= 2:        # 每涨 2% 才写一次
        repo.tasks.update_progress(task_id, p, stage)
        _last[0] = p
```

### 6.5 启动时清理僵尸任务

在 FastAPI `lifespan` 启动钩子里：

```sql
UPDATE agent_task SET status='failed',
       error_code='TASK_INTERRUPTED',
       error_msg='进程重启，任务被中断'
WHERE status IN ('queued','running');
```

## 7. 排障速查

| 症状 | 原因 | 处理 |
|---|---|---|
| `TRANSCRIBE_NO_FFMPEG` 但明明装了 | 进程 PATH 未包含 `D:\Anaconda3\Library\bin`（如从 IDE 启动） | 在 `.env` 里写死 `FFMPEG_DIR=D:\Anaconda3\Library\bin`，代码优先读它 |
| yt-dlp 报 `Sign in to confirm you're not a bot` | 平台风控 | 明确报 `TRANSCRIBE_BLOCKED`，提示"该平台要求登录，暂不支持"，**不做绕过** |
| `Could not load library cudnn_ops_infer64_8.dll` | cuDNN 版本与 ctranslate2 不匹配 | 自动回落 CPU int8；在日志里记一条 warning 即可，不要弹窗 |
| 转录文本没有标点 | whisper 中文固有现象 | 保留原样，不要用正则硬插标点（会插错）；时间戳分段已足够可读 |
| 转录很慢（1 小时视频要半小时） | CPU 模式或 small 模型 | 提示用户可换 `--model base`；文档写明"1 分钟视频约 1 分钟转录"的量级预期 |
| 下载报 `HTTP Error 403` | 需要 cookies | 报 `TRANSCRIBE_BLOCKED`，不实现 cookies 注入 |
| 任务一直 `running` 不动 | 线程池占满（max_workers=2） | 任务中心显示"排队中"；不要盲目调大 worker（转录本身吃满 CPU/GPU） |
| 大文件把磁盘塞满 | 临时音频未清理 | `finally` 里删 `tmp` 目录；`data/tmp/` 启动时清空 |
