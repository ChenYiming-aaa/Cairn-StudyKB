> **这是预览版**：设置里的「检查更新」**不会**发现它（GitHub 的 latest 仍是 v0.2.1）。

## 这一版能做什么

**把文件直接拖进来**
- docx / pdf / pptx / xlsx / txt / md / png / jpg / jpeg / webp，单个上限 200 MB
- 同一份文件重复上传不占额外空间，也不会多出一条内容
- 上传先落盘（2 秒内返回），读字在后台跑；面板上「上传中 45%」与「正在识别 12/30 页」是两条独立的进度
- 上传中可以取消，取消后不留半份原件

**PDF 与图片靠本地识别读字**
- 新组件「本地识别」118 MB，在 设置 → 下载 里装；**模型随包自带，装完断网也能用**
- 没装组件时 PDF 与图片会明说「已存好，但读不出字 · 去设置」，不会假装识别成功
- Word / PPT / Excel / 文本**不需要**这个组件，它们本来就能直接读

**原文页签按格式呈现**
- PDF：左边页图、右边这一页的文字，按页翻；每行认不准的标黄（低于 0.85），整页可疑时页头写一句
- Word：保留标题、列表、表格的版式
- PPT：按页出大纲（标题 / 要点层级 / 演讲者备注）
- 图片：左原图、右识别文字，一屏对照
- 文本：还是原来的纯文本 + 问答定位高亮

**自己划工作区**
- 左栏最上面一段是「工作区」，和下面的「分类」不是一回事：工作区是你建的，分类是机器读完给的
- 建 / 改名 / 删，名字 ≤20 字、允许同名；删工作区只把内容移回「未归类」，不删内容
- 列表勾选可批量移入，详情里一个下拉也能改

**「整理」按内容类型分派**
- 普通资料：还是完整笔记（摘要 / 要点 / 结构化笔记）
- 试卷：只出卷面概览，**不再写笔记**（写笔记会污染题库）
- 图片：只出一句话说明 + 图上看得出的要点
- 正文还是占位（文件没读完）时点「整理」会被拦下，并说明「还在读字」

## 已知限制（预览版，别当 bug 报）

- **识别耗时看每页字数，不承诺秒数**：试卷页（约 350 字）几秒一页，双栏讲义页（约 1560 字）
  实测 15.7 秒/页，30 页讲义要 8 分钟左右。任务在后台跑，可以先干别的
- **试卷导入与按卷练习还没做**（M10）；这版能把试卷读成文字，但还不能拆成题目
- **引用跳页还没做**（M11）；原文页签已经能翻页，检索结果还点不到具体第几页
- **0.2.1 及更早识别的页没有行级置信度**，那些页不会标黄（迁移只加列，不回填）
- 识别组件 118 MB 下载 + 解包 266 MB，磁盘要留够

## 怎么装

1. 手动下载 `Cairn-0.3.0-alpha.1-setup.exe`，双击装（会覆盖旧版，**不动数据目录**）
2. 打开后去 设置 → 下载 装「本地识别」，再拖一份 PDF 或图片进来试试
3. 若弹出「Windows 已保护你的电脑」，选 **更多信息 → 仍要运行**（没有代码签名，不是病毒告警）
4. 想回退：装回 `Cairn-0.2.1-setup.exe` 即可；数据是向前兼容的只加列迁移，**降级后新版本的列会被忽略**
