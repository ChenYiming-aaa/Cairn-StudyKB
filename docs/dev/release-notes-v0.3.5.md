# v0.3.5 · 把话说得跟做的事对上

> **作用域**：v0.3.5 的 GitHub Release 正文。
> **读者**：所有用户（会推给已装 v0.3.3 的人）。
> **发布时**：把这段「作用域 / 读者」删掉再贴 —— 它是写给维护者看的。

这一版**删掉了一个功能（番茄钟）**，另外把 8 处「界面说了、但没真的发生」的地方接上了。

升级方式：设置 → 关于 → 检查更新，或者手动下 `Cairn-0.3.5-setup.exe`。
**数据目录不动**，随时可以装回 v0.3.3（装回去，历史上的计时记录还在，只是那些功能也回来了）。

## 先说删除：番茄钟与「学习记录」下线

去掉的不是「不好用的番茄钟」，是**这一整套计时记录**：顶栏那个迷你计时器、
内容详情里的「开始专注」、「学习记录」页签，以及仪表盘的「本周专注时长」。

理由说直白一点：它记录的是**你坐了多久**，而这里真正要回答的是**你学了什么、记住没有**。
后一件事已经由复习队列和正确率回答，而且回答得更硬 —— 有没有回来、答没答对，是能验证的事实；
坐满 25 分钟不是。留着它，还会让两处数字互相打架：一边「连续 5 天」按计时算，
一边「待复习 / 正确率」按作答算，对不上时你只会觉得两个都不准。

**你的历史计时数据没有删**，数据库里那张表原样保留，只是界面不再显示、也不再写入。

## 你会看到的变化

- **内容进来就自己开始整理**。以前采集完要去任务中心或列表里再点一次「整理」；
  现在网页抓到正文、文件读完字之后自动接着整理，任务中心里能看到它排上了。
  批量导入的一整批**不自动整理**（几十个文件等于几十次模型调用，会卡很久），仍按需点。
- **出题会读你整理好的笔记**，不再每次都拿原文重新读一遍。题目跟笔记的要点更贴，
  同样的题数也更省 token。
- **第一次就答对的题也会回来**（2 天后）。以前只有答错过的题进复习队列，
  于是「今天蒙对了」和「真的记住了」被当成一回事。现在两者都会被再问一次。
- **三处搜标题的地方会说清自己在搜标题**（内容列表、学习页列表、练习选材料）。
  想搜正文里的字，它给一个「去检索」的入口，不用自己猜为什么搜不到。
- **思维导图折进了笔记页**。以前它和笔记各占一个页签，两个页签看的是同一份整理结果；
  现在排在笔记下面，想看结构时展开。试卷仍保留独立的导图页签（试卷没有笔记页）。
- **任务中心按「我在做什么」归组**：收内容 / 整理内容 / 安装组件，
  同一条内容的抓取、补索引、重读折成一行，正在跑哪一步写着「第几步」。
  顺带把 `LLM_HTTP_ERROR` 这类内部字样从界面上撤了。
- **试卷复核后直接开卷**：确认导入之后不再回知识库再点一次，直接进「按卷练」。
- 导航里的「学习」改叫 **「导出」**（页面里生成的产物仍叫「学习页」）。

## 数字口径变了两处，先说来免得你以为坏了

- **仪表盘从 6 块变 5 块**：去掉「本周专注」；顶栏今日条从 4 格变 3 格，去「专注」。
- **「连续学习天数」换了算法**：以前按「那天至少计时过一次」算，计时器没了就会永远是 0。
  现在按**那天答过题、或那天有内容被整理好**算 —— 所以升级后这个数字**可能比昨天大**，
  这不是算错，是以前「只看笔记、没出题」的日子被漏掉了。
