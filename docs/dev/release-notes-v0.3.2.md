## 你会看到的变化

- **做完了有事可做**：任务中心成功的那条现在能点「去看这条」直接跳到内容；
  错题本翻着一屏题也有「去练习」了；内容详情头部多了「练这条」，直接拿这条出题；
  粘贴完一条内容，面板自动关掉并把刚存的那条打开（以前是回到不知道该干嘛的列表）
- **不再一声不响**：点引用但原文里找不到那段话时，PDF / PPT / 图片都会说一句
  「没定位到这一段，停在当前页」；图片原图加载失败会给「再试一次」，而且真的重发请求
- **试卷复核能分清谁说的**：每条待核问题前面标了「规则」或「模型」——
  规则切出来的（比如「这题没认出答案」）和模型补的（比如「选项可能没认全」）该重点核的地方不一样
- **待复核的题看得见自己的答案**：「待人工判断」里每行现在同时显示「你的答案」和「正确答案」，
  以前只有题干和出处，判对错全凭回忆
- **数字对得上了**：「待整理」在今日条写「全库」，与仪表盘的「今日待整理」明确区分，不再同名不同数；
  左栏工作区的「全部」改成「全部工作区」（原来它只清工作区这一项，旁边那个「全部内容」才是清全部条件）
- **不会误点的地方**：批量移入的按钮现在带目标名（「移到 未归类」）、没选目标时禁用；
  练习页题型只剩一种时那颗按钮置灰并说明原因；仪表盘的分类分布可以点了，点一下回到知识库按该分类筛好
- **首次引导说清两个按钮的区别**：一个会下载组件、一个不会，按钮名直接写「下载 N 项并进入」和
  「先不下载，稍后再说」，两条都能进去用

## 只对维护者有意义的部分

- 待判列表补 `user_answer`（`repo/review.py` 的子查询 + 白名单加 key），不新增端点；
  `report()` 仍沿用最近一次作答，人工裁定过的历史不受影响
- 试卷复核的来源标记直接用 `exam/audit` 已有的 `source` 字段（`rule` / `model`），前端此前丢掉了它
- `useLocate` 从返回 `marks` 改成 `{ marks, missed }`：以前 `null` 同时表示「还没问」和「问过没找到」，
  后者在界面上就是点了没反应
- 文案按 `docs/dev/文案规范.md` 回到既有术语：「关键点」→「要点」、「关于」页签 →「关于与更新」；
  同步了 `verify_m7` 的禁止词表与相关断言
- 试用页「问一句」的禁用条件核过一遍：它等价于「材料是空的」，原来那句推断的隐藏顺序不成立，没有加提示
- 验收：`verify_m7` 96/96、`verify_m11 --only ui,locate` 31/31、`verify_m10 --only audit` 41/41、
  `verify_m6` 83/83、`verify_m4` 全绿；本轮浏览器冒烟 27 条
