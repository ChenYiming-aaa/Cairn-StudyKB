# 图标语义映射表

> **作用域**：`frontend/src/ui/Icon.vue` + `frontend/index.html` 里那份 symbol 仓库
> （38 枚 / 24×24 画布 / 1.75px 描边 / `currentColor`）。只回答「一个概念绑哪一枚图标」，
> 不写组件用法；用法见 `ui/Icon.vue` 顶部注释。
> **新增图标前先查这张表**：语义重复就改文案或复用，不要再画一枚。
> 表头三列：图标 id、承载的概念、出现位置。

## 主导航（一级入口，永远配文字标签）

| id | 概念 | 位置 |
|---|---|---|
| `library` | 知识库（内容资产整体） | 顶栏导航「知识库」 |
| `search` | 检索（跨正文搜索 / 问答） | 顶栏导航「检索」 |
| `export` | 导出（把内容装订成离线文件） | 顶栏导航「导出」 |
| `practice` | 练习（做题） | 顶栏导航「练习」 |
| `review` | 复习（到期队列） | 顶栏导航「复习」 |
| `tasks` | 任务中心 | 顶栏右侧 + `/tasks` |

> `dashboard` 只用于仪表盘，**不进一级导航**——它的入口在知识库的「今日」条里。

## 顶栏与全局

| id | 概念 | 位置 |
|---|---|---|
| `signal` | 服务连接状态 | 顶栏「已连接 / 未连接」 |
| `plus` | 采集内容（主动新增） | 顶栏主按钮 |
| `settings` | 设置 | 顶栏齿轮 |
| `panel-left` | 收起 / 展开左栏 | 顶栏与左栏窄条 |
| `panel-list` | 收起 / 展开列表栏 | 顶栏（仅知识库页） |
| `chat` | 问答历史 | 检索页侧栏 |
| `refresh` | 重新加载 / 重试 | 错误态、列表刷新 |

## 状态与提示

| id | 概念 | 颜色来源 |
|---|---|---|
| `check` | 成功 | `--c-success` |
| `alert` | 警告 / 失败 | `--c-warning` / `--c-danger` |
| `info` | 说明 | `--c-primary` |
| `clock` | 待处理 / 时间 | `--c-text-3` |
| `inbox` | 空态 | `--c-text-3` |
| `spinner` | 加载中（配 `.is-spinning`） | `currentColor` |

## 状态语义提醒

**状态永远不能只靠颜色表达。** 徽标、任务状态、答题对错一律「图标 + 文字 + 颜色」三者齐备：
`<Badge tone="success" icon="check">已整理</Badge>`。
