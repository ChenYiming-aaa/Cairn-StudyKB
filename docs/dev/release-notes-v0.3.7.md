## 3. 维护者备注（不贴 Release）

### 3.1 逐条对应的改动

| 正文点 | 改动 |
|---|---|
| 1 已整理换成淡绿，与待整理分开 | `app.css` 的 `.badge-ready` 从共用中性变量改成 `success-soft` 淡绿底 + `success-ink` 绿字；`.badge-pending` 保持中性灰。四态现在各一色：待整理灰 / 整理中琥珀+脉冲 / 已整理淡绿 / 失败红。2026-11-22 曾为避免「一排饱和绿胶囊压标题」把已整理压成中性，代价是与待整理完全一样，这版恢复绿色但用淡底，区分状态又不压标题。`verify_m7` 的对比度断言：`badge-ready 4.82:1`、`badge-pending 6.17:1`，均过 AA。README「知识库」段补了一句四色说明。 |
| 2 采集视频不再闪黑框 | 新增 `backend/app/subproc.py` 放唯一的 `CREATE_NO_WINDOW`（0x08000000 / nt）。装上它的是两处漏掉的 ffmpeg 子进程：`env_probe._version()` 的 `ffmpeg -version`（每次启动/进设置就跑，所以表现为「一进来就弹」）与 `transcriber._extract_audio()` 的抽音轨（真转录时跑）。`component_proc.py` 原有的局部常量收归到这里，三处共用。根因：后端在安装包里是无控制台的 windowed exe，Windows 下 spawn 控制台程序会为子进程新建窗口。 |

### 3.2 只有两件事，为什么还是编号

各自独立可验，合并成一句会变成 20 字以上的并列长句，反而更难读。
