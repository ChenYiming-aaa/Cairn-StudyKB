### 3.1 旧版正文（2026-11-18 统一前）

## 这是什么

Cairn **v0.2.0** 的三个可选组件包。**这不是应用本体** —— 装 Cairn 请到 [v0.2.0 Release](https://github.com/ChenYiming-aaa/Cairn-StudyKB/releases/tag/v0.2.0)。

正常情况下你**不需要手动下载这里的东西**：打开 Cairn → 设置 → 下载 → 点「安装」，程序会自己从这里取包、校验 sha256、解压到 `%APPDATA%\Cairn\components\`，过程中可以取消、可以续传。

| id | 组件 | 文件 | 大小 | sha256 |
|---|---|---|---|---|
| `embed` | 向量检索 | cairn-embed-0.2.0.zip | 262 MB | `7c24134e70d39c59…` |
| `asr` | 视频转录 | cairn-asr-0.2.0.zip | 100 MB | `571b39991667de7b…` |
| `browser` | 网页渲染 | cairn-browser-0.2.0.zip | 49 MB | `45ab79be6678e5bc…` |

## 每个组件能干什么

- **embed 向量检索**（262 MB）— 让问答按意思找，而不只是按字面。不装则检索退化为纯全文，界面会明示
- **asr 视频转录**（100 MB）— 没有字幕的视频转成文字。不装则只支持本来就带字幕的视频
- **browser 网页渲染**（49 MB）— 知乎这类必须跑脚本才出正文的站点。不装也能采大部分网页

模型文件（bge 100 MB / whisper 500 MB）**不在这些包里**，仍是首次使用时从 `hf-mirror.com` 下到数据目录。

## 手动安装（网络受限时）

1. 下载对应的 zip
2. 解压到 `%APPDATA%\Cairn\components\<id>\`（id 是上表第一列的 `embed` / `asr` / `browser`）
3. 重启 Cairn，设置 → 下载 里应该显示「已安装」
4. 校验：`certutil -hashfile <zip> SHA256` 应等于上表 sha256

要求 **Cairn ≥ 0.2.0**（清单里 `min_app_version` 是 0.2.0，低版本会拒绝启动组件）。
