# 文案与信息布局瘦身（2026-11-22）

> **作用域**：`frontend/src/` 里**界面上看得见的字**——按钮、标题、提示、说明、空态、页脚、
> 以及 `components.json` 里给用户看的组件介绍。不含代码注释、日志、API 字段名。
> **作用域边界**：`Setup.vue` / `Try.vue` 是引导页与试用页，讲解本身就是它的功能，只做了
> 词汇层面的收短，没有按「删解释」处理；`docs/` 里的历史审计文档不回改。
> **判据来源**：`docs/dev/文案规范.md`（术语、语气、禁词、空态三段式）；冲突时以规范为准。

## 结论

界面上 439 个字被删掉（9 个界面，改前 4308 → 改后 3869，−10%）。删掉的大多是
**同一件事的第二次说明**：设置四个页签各带一行副标题、六个配色卡各带一句色系描述、

另有 3 处「必须靠一段话才看得懂」的地方，改成了**看结构就懂**：

| 原来靠这段话 | 现在靠这个结构 |
|---|---|
| 「只搜标题。正文里的词，去「检索」里搜。」（`SearchScopeHint`，三处） | 空态标题直接写范围：`标题里没有「xx」`，下一句就是出路 |

**字数不是目标**。字越少不一定越好读——`Dashboard` 的「今天还没动，整理一篇或答几道都算」
改成「今天还没动」少了 13 个字，但把「什么算学过」这个问题留给了用户；这一条是拿
「同一句话在另一个地方已经说过（空态里有动作）」换来的，不是单纯删。

## 四条判据（这次用来决定删不删）

1. **有没有第二个地方说同一件事**：页签名与页签副标题、字段标签与 placeholder、
   按钮与按钮旁边的说明，都算「同一件事说两遍」。
2. **说完之后用户会不会多做/少做一件事**：会，就是有用的（「只留正文；要登录的页面抓不到，
   改用粘贴」改变选择）；不会，就是噪音（「探测不会改动你的地址和 Key」——按钮 title 已写「只读」）。
3. **能不能改成结构**：顺序、范围、状态、开关，这四类信息优先做成看得见的东西
   （序号、标题里的范围词、禁用态、标签），而不是加一句解释。
4. **删掉之后这一段会不会读成「坏了」**：会，就保留一句状态话（`这次没给摘要`），但**去掉建议**
   ——建议就在页头那个按钮上。

## 删/改清单（按界面）

**知识库**：列表空态三句（没有匹配 / 换个关键词 / 只搜标题……）收成
`标题里没有「xx」` + `换个词，或者去检索正文`（新全局 `.link-btn`）；截断提示
「仅显示前 50 条，共 120 条；用关键词或分类缩小范围」→「显示前 50 条 / 共 120 条」。

**仪表盘**：正确率副行原来「今日 3 次作答 · 累计 33%（3 次作答）」——同一个数字报两遍，
改成累计次数与今日不同时才补「（共 N 次）」；连续学习三句各收成一句（`今天已学` /
`今天还没动` / `今天整理或答题就记 1 天`）。

**检索**：缺向量组件时「现在只能按关键词搜。装上「向量检索」就能按意思搜」+「去安装」
→ `只能按关键词搜` + `装向量检索`；其余三条回退提示各去掉半句；空态副句
「答案只来自你采集的内容；找不到会直接说没有。」→「只从你的内容里找，找不到就说没有」。

**练习**：页副题去掉承诺式长句；删掉试卷那段说明（见上表）；空态两句各砍一半；
截断提示同上；搜索无结果并进空态一行。

**复习**：页副题去掉「2 → 4 → 7 → 15 天」的算法序列；面板左上「今日待复习 2 题，
一次最多做 20 题」——页签已是「今日待复习」、按钮已带题数，只留「一次最多 20 题」；
错题本说明「最近一次作答仍答错的题。复习答对后自动移出。」→「只算最近一次答错的题」。

**任务中心**：删掉每种任务的一句解释（单条一组时贴在行下，一屏七行同一句）；
失败行的提示只说原因（`缺「文字识别」组件`），右边就是「去装组件」按钮。

**学习页**：页副题、空态各收短；标题 placeholder 与标签不重复；预览上方那行
「将按此顺序成页：…」删除，序号进勾选框（新 `.pick-box`：勾上就变成第几个）；
文件信息「单文件离线 · 浅色排版（便于打印）」→「单文件 · 可打印」。

**详情**：缺摘要/要点从「（模型这次没给摘要，可以重新整理试试）」改成
`这次没给摘要` / `这次没给要点`；整理中「正在重写，下面是上一版；整理完会自己刷新」
→「正在重写，下面是上一版」；未整理空态不再念操作步骤，改说结果。

**采集面板**：关闭提示、拖放区支持格式、链接页说明各收一句；标题标签与 placeholder
原本都在说「可留空、模型会起标题」，留一处。

**设置**：四个页签副标题整列删除；模型页删「两套服务…」总述、「探测不会改动…」；
Key 说明「只写进本机 .env，不显示、不上传、不进日志。」→「只写进本机 .env」；
任务矩阵脚注两段 →「改完下一次调用就生效」；外观页删六张卡的色系描述与两条使用建议；
下载页总述、演示版提示各收一句，四张卡不再各写一遍「演示版不能装」；
页脚隐私声明收短。

**组件介绍**（`backend/app/components.json` + 演示层同一份）：四条 `why` 各收成一句
——页面要回答的是「装它干什么」，不是「不装会怎样」。

## 刻意没做的

- **`Setup.vue` / `Try.vue` 的段落没删**。它们讲的是「第一次怎么配」「这个试用页会发生什么」，
  删了等于把人扔在空白表单前。只把「想换服务商、或者给整理/问答/出题/批改分别挑模型？」
  这类反问句留着——它承担的是「这里还能细调」的发现功能，不是解释。
- **`FAILURE_FIX` 的四条提示没有删**，只砍掉「去哪儿点」那半句。失败是用户唯一会停下来读字的时刻，
  原因必须留。
- **没有为了减少字数去合并术语**。`今日待复习 / 还没到期 / 错题` 三个数各有各的名字，
  合并会让同一屏两个数字重名（跨界面审计 4-5 的结论）。
- **没有动页签、按钮的既有命名**：`摘要与要点`、`开始复习`、`按卷练` 都是验收脚本与规范的锚点。
