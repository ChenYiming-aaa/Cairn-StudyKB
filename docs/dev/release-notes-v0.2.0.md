# v0.2.0 · 安装包小了一半多，组件按需装，设置里能自己更新

> **作用域**：v0.2.0 的 GitHub Release 正文，发布时整篇贴进去（`gh release create --notes-file`）。
> **读者**：从 v0.1.0 升上来的用户，以及第一次下载的人。
> **约束**：更新器只显示前 20 行（`AboutTab.vue` 截断），所以开头几行必须自己说得清。
> **不写**：内部实现与验收数字 —— 那些在 `CHANGELOG.md` 和 `milestones/M8-体积与更新.md` 里。

> **如果你现在用的是 v0.1.0：这次要手动下载一次安装包。** 0.1.0 里还没有更新器，
> 装上 v0.2.0 之后，才能在「设置 → 关于 → 检查更新」里一键升级。

- 安装包 **426 MB → 172 MB**，装完磁盘 **1.4 GB → 474 MB**（不含可选组件）
- 向量检索 / 视频转录 / 网页渲染拆成**三个可选组件**，用到再装、随时卸载
- 新增**检查更新**：下载、校验 sha256、起安装程序，全程不动数据目录
- **功能一条没砍**：缺哪个组件就退到原来那条降级路径，不崩也不假装成功

## 怎么装

1. 下载 `Cairn-0.2.0-setup.exe`，双击
2. 若弹出「Windows 已保护你的电脑」，选 **更多信息 → 仍要运行**（没有代码签名，不是病毒告警）
3. 可以改安装目录，不需要管理员权限

**升级不会动你的数据**：笔记、索引、题目、作答都在 `%APPDATA%\Cairn\data.db` 里，安装和卸载都不碰它。
想稳一点就先复制一份 `Cairn` 文件夹。

## 三个可选组件

| 组件 | 装它才能 | 大小 |
|---|---|---|
| 向量检索 | 语义检索（与全文一起做混合召回） | 262 MB |
| 视频转录 | 没有字幕的视频转成文字 | 100 MB |
| 网页渲染 | 抓知乎这类必须渲染的站点 | 49 MB |

在 **设置 → 下载** 里装，或首次引导页勾选。不装也能用，只是对应功能降级并在界面上说清楚。
三个全装约额外 411 MB —— 按需，不是强制。

## 升级须知

- 更新是**全量包**（约 172 MB，就是完整安装包），没有增量更新
- **不支持降级**：升到新版要回退，只能手动装旧版安装包
- 卸载组件只删 `%APPDATA%\Cairn\components\<组件>\`，数据一条不动
- 从源码运行（`npm run dev`）时更新按钮会显示「开发模式不检查」，这是刻意的

## 校验

安装包的 sha256 见 Release 附件的 `Cairn-0.2.0-setup.exe.sha256`；
更新器会自动比对它，手动下载的话可以先算一遍再装。
