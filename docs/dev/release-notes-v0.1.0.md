# Cairn v0.1.0 — 第一个可用版本

> **作用域**：GitHub Release 正文（v0.1.0），发布时整段粘贴到网页 Release 里；只影响发布说明，不约束代码。
> **不要读**：这份不是设计文档，做功能改动时不必看它。

## 这是什么

把网页 / 视频 / 文章收进本地知识库，AI 自动整理成可检索、可复习的知识资产：检索问答、学习页、
出题练习、间隔重复复习、番茄钟与学习统计，全部在一个 Windows 桌面应用里完成。数据存在本地，
唯一出网的动作是调用你自己配的大模型接口。

## 下载

**`Cairn-0.1.0-setup.exe`（约 426 MB，Windows 10/11 x64）**

不需要装 Python、Node、ffmpeg —— 安装包自带运行时与 ffmpeg。装完第一次启动会自动进「环境」引导页，
把模型 Key 填进去即可用。

> ⚠️ 安装包**没有做代码签名**，Windows 会弹「已保护你的电脑」。点 **更多信息 → 仍要运行** 即可，
> 这不是病毒告警，只是"没见过这个发布者"。

## 这一版能做什么

- **采集**：网页抽正文；视频优先用自带字幕，没字幕才本地转录；纯文本直接粘贴
- **整理**：AI 重写标题、摘要、3–6 条要点、结构化笔记、分类与标签，可手改、改完自动重建索引
- **检索问答**：FTS5 + 向量两路召回，答案带 `[n]` 引用可跳回原文；问答历史可回看且不重复调模型
- **学习页**：多条目生成单文件离线 HTML（含思维导图、代码高亮），可预览、下载、分享
- **出题练习**：四种题型三档难度，题面流式生成，答完立即判定，简答题 AI 批改
- **复习**：错题按 1 → 2 → 4 → 7 → 15 天自动回来，错题本按「最近一次仍答错」筛选
- **专注**：番茄钟，刷新/切页/重启后端都不丢计时，结束后写进条目的学习记录
- **仪表盘**：今日待整理、待复习、连续天数、今日正确率、本周专注、分类分布

## 安装与卸载

1. 双击 `Cairn-0.1.0-setup.exe`（如被 SmartScreen 拦，见上面的提示）
2. 安装向导可改目录，默认装在当前用户目录下，**不需要管理员权限**
3. 首次启动约 4–6 秒出界面（先起后端再建窗口，不会白屏）
4. 卸载走「应用和功能」里的 Cairn；**卸载不会删你的知识库**，数据在 `%APPDATA%\Cairn\`

## 首次使用要下载的东西

| 项 | 大小 | 什么时候 |
|---|---|---|
| 向量模型 `bge-small-zh-v1.5` | 约 92 MB | 第一次做语义检索时自动下（从 hf-mirror 镜像） |
| 语音识别模型 `faster-whisper small` | 约 539 MB | 只有「视频没有字幕」需要转录时才下 |

## 已知限制（就别报 bug 了，这些都是已知的）

- 安装包未签名，SmartScreen 会拦一次；正式分发要买证书
- 冷启动约 6.7 秒（首启建表 + 杀软扫 1.4 GB），热启动约 4 秒；卸载耗时可达十分钟
- URL 规范化只去 fragment 不去 query，`?spm=` / `?utm_source=` 会让同一篇文章变成两条
- 多选题偶尔出现「四个选项全对」；prompt 已约束但没有量化断言
- 题目 / 作答 / 复习记录没有保留策略，长期使用数据会持续增长
- 只有 Windows x64 安装包；源码跨平台但未在其他平台验证
- 前端视觉与交互还有优化空间 —— 这一版优先保证功能正确
- 发布前的安装/卸载/重装闭环只在一台机器上跑过，尚未在第二台机器上验证
