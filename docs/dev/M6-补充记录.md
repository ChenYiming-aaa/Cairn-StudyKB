## 一、必须裁决的三条

### S-1 探测成功会顺手把模型列表写进配置（**待裁决**）

`POST /api/settings/probe` 成功且拿到列表时，会把 `models` 写进 `settings.json`（`routers/settings.py` 末尾）。
好处：下次打开设置页模型的候选就是真实的，不用再点一次探测。
坏处：**一个读性质的「探测」产生了持久化副作用**——用户点了探测但不想保存，配置已经被改了；如果探测的是别人的
`base_url`，现在的 `base_url` 也会被一起写进去。

建议：保留便利性，但只在 `provider` 的 `base_url` 与已保存值一致时才回写 `models`；
或干脆去掉，改为「探测结果只进前端状态，用户点『保存』才落盘」。
M6 文档 §2.3 没有约定这条，现在的实现是我自己加的。

### S-2 `llm_call_log` 没有 `effort` 列（**待裁决**）

T6.3 要求「`_write_log()` 记录实际使用的 model 与 effort」。现在的实现只记了 `model`
（`llm_call_log` 表结构里根本没有 `effort` 列）。补充 effort 需要一次 schema 迁移
（`app/db/schema.sql` + 迁移脚本 + 旧库兼容）。

取舍：模型已经能反推大部分排障问题；加列的价值是「同一个模型下 low 与 high 的耗时/成本差异」可对账。
建议在 M7 做成本统计时一起加，而不是现在为一个字段单独迁移。

### S-3 `config.py` 在显式 `--data-dir` 时仍会回落读项目根 `.env`

`load_settings()` 里 `if env_file != ENV_FILE: load_dotenv(ENV_FILE, override=False)`。
这是为了「验收脚本用临时目录时也能拿到 Key」加的，但代价是：

- 验收脚本里「缺 Key」这类用例会被真机 `.env` 干扰（`verify_m6` 第一版就踩了，最后靠手动抹掉 `.env` 里的键才验通）
- 「临时数据目录完全隔离」这个假设不成立：换个数据目录并不能得到一套干净配置

建议加一个开关（`CAIRN_ENV_STRICT=1` 时不回落），验收脚本一律开 strict。
**这一条不改，以后每个验收脚本写「没有 Key 会怎样」都要绕一圈。**

## 三、Part 2（主题 / 外观）必须一起解决的

### S-8 主题的派生规则自相矛盾：`text-3` 达不到自己定的 3:1

M6 §3 写「`--c-text-3` = text-2 与 Background 按 45% : 55% 混合」，同时写「硬标准 `text-3` ≥ 3:1」。
实测（六套全部）：**2.19–2.24 : 1**，一套都过不了。同理 `teal` 的调色板 `On Primary` 是黑色，
而 `app.css` 里 `.btn-primary { color: #fff }` 写死白色 → 3.74:1，也不达标。

已算好的修法（Part 2 直接用）：

- `text-3` 由脚本按「混合到恰好 ≥ 3.05:1」反解混合比例（浅色约 62%–70%，深色按明度反解）
- 新增 `--c-on-primary`：浅色取调色板 `On Primary`（`teal` 是黑，其余白），深色取主色的极暗版本
- 深色底不能沿用浅色的饱和度（`notes` 的 `#FFFBEB` 饱和度 88%，16% 明度下变成深橄榄 `#4E3F04`，
  不像暗底，还会把 `danger` 的对比度压到 2.87）→ 暗底饱和度封顶 22%

按上面三条重算后，六套 × 两模式 × 八组对比度全部达标（`text-1`/`text-2` 4.5:1，
`text-3`/`success`/`warning`/`danger` 3:1，`on-primary` on `primary` 4.5:1）。

### S-9 27 处写死颜色，暗色下会「白底白字」

`grep '#[0-9a-fA-F]\{3,6\}' frontend/src` 出的 27 处，集中在：

| 整理中徽标 | `#fdf3e3` / `#f0dcbb` | `app.css`、`ItemDetail.vue` |
| 成功浅底 / 描边 | `#eaf4ee` / `#cfe4d7` | `app.css`、`ItemList.vue`、`Ask.vue`、`QuizRunner.vue` |
| 失败浅底 / 描边 | `#fbeeec` / `#f0cfcb` | `app.css`、`QuizRunner.vue` |
| 高亮（`<mark>`） | `#fbeaa8` / `#f7e7cd` | `RawPane.vue`、`Ask.vue` |

`--c-mark`、`--c-primary-hover`。Part 2 会连带把 27 处全替换掉，否则暗色主题只能算「半成品」。

### S-10 `index.html` 的 `theme-color` 写死了 `#3f6f5f`

换主题后浏览器/系统标题色不跟着变。`useTheme()` 里要顺手改 `<meta name="theme-color">`。
