# v0.2.1 · 修一个「装完向量组件却搜不出语义」的问题

> **作用域**：v0.2.1 的 GitHub Release 正文，发布时整篇贴进去。
> **读者**：已经在用 v0.2.0 的人（这就是给你发的补丁版）。
> **约束**：更新器只显示前 20 行，开头几行必须自己说得清。

> **如果你现在用的是 v0.2.0**：设置 → 关于 → 检查更新，一条链路就能升，数据不动。
> **组件不用重下** —— 三个组件包没变，装的还是原来那些。

- 修：**先攒内容、后装「向量检索」组件**时，之前入库的条目拿不到向量，语义检索对它们等于没开
- 现在装完组件会自动给全库补一次向量，并把约 92 MB 的 `bge` 模型一起拉下来
- 只在组件真能跑（握手通过）时才补 —— 坏包不会在任务中心留下一条注定失败的红条目
- 其他行为不变；这是一次只含一处修复的补丁版

## 你会不会碰上

只有一种顺序会踩到：**先采集了一批内容，之后才去装「向量检索」组件**。
那种情况下老条目仍能用全文搜到（中文两字词也搜得到），但「按意思搜」对它们不生效。

如果你当时是「先装组件、再采集」，或者压根没装这个组件，这次更新对你没有可见变化。

## 怎么装

1. 推荐：**设置 → 关于 → 检查更新** → 下载 → 打开安装程序
2. 或者手动下载 `Cairn-0.2.1-setup.exe`，双击装（会覆盖旧版，**不动数据目录**）
3. 若弹出「Windows 已保护你的电脑」，选 **更多信息 → 仍要运行**（没有代码签名，不是病毒告警）
4. 更新是全量包（约 172 MB）；**不支持降级**，回退只能手动装旧版

## 校验

安装包的 sha256 见 Release 附件的 `Cairn-0.2.1-setup.exe.sha256`，更新器会自动比对。
