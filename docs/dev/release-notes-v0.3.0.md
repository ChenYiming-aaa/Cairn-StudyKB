# v0.3.0 · 本地文件、本地识别、试卷导入、原件级呈现

> **作用域**：v0.3.0 的 GitHub Release 正文。
> **读者**：所有用户（这是**正式版**，会推给 v0.2.x 用户）。
> **发布时**：把这段「作用域 / 读者」删掉再贴 —— 它是写给维护者看的。

v0.3 把「本地文件」这条路走完了三步：**读得进去**（本地识别）、**排得成题**（试卷导入）、
**看得见原件**（PDF 原样呈现 + 引用跳到那句话）。v0.2.1 之前 Cairn 只能吃网页和纯文本，
现在 docx / pdf / pptx / xlsx / 图片都能直接拖进来。

升级方式：设置 → 关于 → 检查更新，或者手动下 `Cairn-0.3.0-setup.exe`。
**数据目录不动**，随时可以装回 v0.2.1。

## 这一版新添的三件事

### 一、本地文件与本地识别（v0.3.0-alpha.1 已有）

- docx / pdf / pptx / xlsx / txt / md / png / jpg / jpeg / webp 直接进库，单个上限 200 MB
- 同一份文件重复上传不占额外空间，也不会多出一条内容；上传 2 秒内返回，读字在后台跑
- PDF 与图片靠**可卸载的「本地识别」组件**读字（118 MB，**模型随包自带，装完断网也能用**）
- 没装组件时明说「已存好，但读不出字 · 去设置」，不会假装识别成功
- Word / PPT / Excel / 文本**不需要**这个组件
- 自己划工作区；整理按内容类型分派（试卷只出卷面概览，图片只出一句话说明）

### 二、试卷导入与按卷练（本次新增）

把一份卷子拖进来，走到「能开始做」只要三步：**识别 → 复核 → 确认导入**。

- **拆题**：规则先切题号、选项、答案速查表，切不出的字段才交给模型补
  （`answer` / `type` / `score`）。**题干与题号任何情况下不让模型改** ——
  模型改题干等于悄悄换了一道题
- **复核页**：左边是这一页的卷面图、右边是拆出来的题卡，题干 / 选项 / 题型 / 答案都能改。
  **中途退出什么都不落库**，点「确认导入」才一次写进去
- **检查题目**：复核页一打开就把这批题过一遍 —— 缺答案、题干断在半路、选项混进题干、
  选项重复、答案越界这些规则能判的直接标出来，读不通的才问模型。
  **答案一个字都不生成**（缺答案只报不补），模型给的改法也不自动应用，界面上「用这条 / 撤回」
- **文字校对**：纠意识别错字，四道闸门守着 —— 只收结构化 diff、编辑距离有上限、
  **原文永不覆盖**（随时能退回去看原样）、答案行只许改标点
- **按卷练**：题号按数值排（第 10 题不会跑到第 2 题前面），「再做一遍」还是同一套卷
- **文件夹批量导入**：一次扫一个文件夹（只扫这一层），最多 100 个文件，
  一个失败不拖垮整批，最后分「成功 / 重复 / 失败」三堆放
- 练过的题删不掉：删除会把题摘出卷子（`number` 置空）留在库里，历史作答记录跟着保留

### 三、原件级呈现（本次新增）

**PDF 改成连续滚动**：一屏里顺着往下读，没有「翻页」这个动作了。每页先用识别时落下的页图垫着，
原件解析好之后换成清晰的原样渲染；**只渲染看得见的那几页**，30 页的件滚起来也不卡。

**点引用能落到那一段**：检索命中卡和问答里的 `[n]` 点进去，原文页签不只是「打开这份内容」，
而是直接滚到那句话并标黄 —— PDF 翻到第 N 页，Word / PPT / 图片在已经渲染出来的文字里找那段话。
跨页的段落也能落对页；一段话在两页都出现过时，落在**这段字主要在的那一页**。

**Word 里嵌的图能看到了**：图存在数据目录里、按内容哈希去重（同一张图插两次只存一份），
正文里只有地址，不会把整份文档撑成几十兆。

## 已知限制

- **识别耗时看每页字数，不承诺秒数**：试卷页（约 350 字）几秒一页，双栏讲义页（约 1560 字）
  实测 15.7 秒/页，30 页讲义要 8 分钟左右。任务在后台跑，可以先干别的
- **识别漏一整行，那道题就没了**：复核页会说「第 N 题没认出来」，得手动补
- **校对一次只改一行**，不合并断句；图表题与跨页题干仍不够干净
- **引用定位找不到就停在开头**，不弹提示（那段字被整理删掉、或横跨两个块时会这样）
- **Word 的图统一压到长边 1600 / JPEG q85**，要原图得回 `.docx` 本身
- **老内容不会自动长出图**：0.3.0 之前读过的 Word 要点一次「重新读一遍」
- 图片只有一页、PPT 有页无页图，所以这两类的「跳转」是文内定位，不是翻页
- **0.2.1 及更早识别的页没有行级置信度**，那些页不会标黄（迁移只加列，不回填）
- 识别组件 118 MB 下载 + 解包 266 MB，磁盘要留够

## 怎么装

1. 设置 → 关于 → 检查更新，或手动下 `Cairn-0.3.0-setup.exe`（会覆盖旧版，**不动数据目录**）
2. 打开后去 设置 → 下载 装「本地识别」，再拖一份 PDF 或图片进来试试
3. 若弹出「Windows 已保护你的电脑」，选 **更多信息 → 仍要运行**（没有代码签名，不是病毒告警）
4. 想回退：装回 `Cairn-0.2.1-setup.exe` 即可；数据是向前兼容的只加列迁移，
   新版本加的列在旧版里会被忽略
