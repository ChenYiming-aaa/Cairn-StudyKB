#### 你会看到的变化

- **交卷后结果页留住了**：分数、每题对错、参考答案都在，不再一闪回到空列表；
  底下的按钮按你来路写「回到复习列表」或「回到错题本」。
- **答题中途离开，回来会问一句**：「发现您上次中途退出答题（第 3 / 5 题），是否继续上次答题？」
  选「继续」就停在第 3 题，标题旁标着「接着上次」。练习页那一轮生成的题也一起回来了。
- **错题本可以直接练**：多了一个「练这些错题（N）」，拿这批题再练一遍；
  答对了它就自己移出错题本，答错还留着。「去练习出新题」也还在。
- **检索与问答之间来回，输入和结果都不丢**；问不出答案时给两个下一步：
  「改成原文命中」用你刚才那句重搜，「采集这条内容」把它存进知识库。
- **「待整理」只剩一个数**：顶部条与首页卡片都算**全库**，不再一个说今天、一个说全部。
- **重启之后不再永久卡「整理中」**：上次没收尾的整理，重开程序会放回「待整理」，点一下就能再来。
- **试卷复核读库里那一版**：以前导入过的试卷再进来，不会再让模型重解析一遍覆盖你手改过的题；
  改了题没导入就离开，会先问一句「这页改了 N 道题还没导入，离开就没了」；
  原件还没读完时「导入试卷」是灰的，旁边写着还差什么、去哪儿补。
- **组件装完真的会通知你**：装的过程中可以关掉设置窗口去干别的，
  装好会弹「「本地识别」装好了，回原来的页面就能用」。缺组件的地方现在既给「去装」也给「重读」。
- **修好了一个点不动的按钮**：「重读」从 v0.3.0 起就是坏的 —— 点下去报错，
  PDF 和图片永远读不出字。现在点了就重读。

#### 只对维护者有意义的部分

- 17 处断点的清单、改法与实机证据见 `docs/dev/跨界面连贯性审计-2026-11-16.md`；
  这轮补测还把「错题本整轮」与「真装 118 MB 组件」两条之前没跑完的走了一遍。
- **「重读」怎么坏的**：`POST /api/knowledge/{id}/ocr` 的签名写的是 `body` 可空，
  实现里却直接读 `body.pages`；界面上的「重读」正好不带请求体 —— 于是 500。
  以前 `verify_m9` 只打 `json={}`（会构造一个空 body），所以这条一直是绿的；
  现已补一条按真实调用方式（不带体）打的用例。
- 冒烟脚本的夹具也改了一处：启动时的「整理中 → 待整理」回收会把种在服务启动前的素材收走，
  改成等服务起来之后再摆回去（否则待整理数多一条、L4 拿不到「整理中」）。
